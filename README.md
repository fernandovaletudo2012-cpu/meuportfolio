# Portfólio de Fernando Santos

Site estático em português, pronto para GitHub Pages. Não precisa instalar dependências ou compilar.

## Abrir

Abra `index.html` no navegador. Mantenha os demais arquivos e a pasta `assets` juntos.

## Publicar no GitHub Pages

1. Crie um repositório chamado `portfolio-fernando` pelo GitHub Desktop e publique-o no GitHub. Um repositório público funciona com GitHub Free.
2. Copie o conteúdo desta pasta para a raiz do repositório: `index.html`, `style.css`, `script.js`, `projects.js`, `.nojekyll` e `assets/`.
3. Pelo GitHub Desktop, faça um commit e clique em Push origin. Use o GitHub Desktop porque o PDF original tem cerca de 54 MB e excede o limite de envio de arquivos pela página web do GitHub.
4. No repositório online, abra Settings → Pages.
5. Em Source, selecione Deploy from a branch. Escolha `main`, pasta `/(root)` e clique em Save.
6. Aguarde a publicação. O endereço aparecerá nas configurações de Pages.

Documentação oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Atualizar o conteúdo

- Projetos, descrições, fotografias e links: `projects.js`.
- Apresentação, trajetória e contatos: `index.html`.
- Cores e aparência: `style.css`.
- Imagens: `assets/`. Use caminhos relativos para funcionar também em repositórios com subpasta.

## Identidade visual selecionada

Logo horizontal 01 (branco e dourado) e Ícone 01 (dourado). Foram removidas apenas as margens transparentes e reduzida a resolução para uso web, preservando a arte. As outras versões não fazem parte do site.

## Recursos

20 projetos, filtros por linguagem, galeria em janela ampliada, links de registros do PDF, menu para celular, contato por WhatsApp, Instagram e e-mail e acesso ao PDF completo. As imagens e os dados vieram do portfólio fornecido. Não há formulário ou armazenamento de visitantes.
